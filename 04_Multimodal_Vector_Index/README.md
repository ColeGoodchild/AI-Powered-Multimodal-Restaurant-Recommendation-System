### Objectives
This notebook:

1. Constructs retrieval-ready documents from structured restaurant data
2. Generates dense embeddings for both text and image modalities
3. Builds separate vector indexes for articles and food images using Chroma
4. Persists multimodal vector databases for downstream retrieval tasks
5. Prepares the retrieval backbone for similarity search and metadata filtering

These capabilities form the foundation of a production-style multimodal RAG retrieval pipeline.
