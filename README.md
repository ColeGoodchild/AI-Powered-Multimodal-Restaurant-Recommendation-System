# AI-Powered Restaurant Recommendation System
## Built a Complete, End-To-End AI Application from Scratch

## Executive Summary:

1. Structured real-world culinary data
2. Exposed the data through MCP tools
3. Connected a client to an MCP server
4. Integrated the tools with a language model that can interpret user questions, retrieves relevant restaurant information and generates helpful responses

## Breakdown of each step:
1. Transforms unstructured restaurant descriptions into structured JSON
2. Enriches the existing data source with multimodal insights (image captioning and identification)
3. Creates a Command-Line Data manager to perform CRUD operations on the data
